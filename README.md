# DynamicStructures

Практическое занятие №3 «Динамические структуры»: WPF-приложение на C# (.NET 10).

## Запуск
Visual Studio: открыть `DynamicStructures.sln`, запустить проект `DynamicStructures`.
Консоль: `dotnet run --project DynamicStructures`; тесты: `dotnet test`.

## Пункты выпадающего списка
| Пункт | Что делает |
|---|---|
| Стек: операции из файла | Выполняет `input.txt` на своём стеке (связный список), график времени |
| Стек: постфиксное вычисление | Вычисляет каждую строку файла как постфиксное выражение |
| Стек: инфикс → постфикс | Переводит формулу вроде `(7+8)/(3+2)` в `7 8 + 3 2 + /` и вычисляет |
| Очередь: List<T> против Queue<T> | Те же операции на двух очередях, две линии на одном графике |
| Списки: 4 алгоритма | Переворот, перенос первого/последнего, число различных, удаление неуникальных |

Формат `input.txt`: `1,значение` — вставка, `2` — удаление, `3` — вершина/начало, `4` — пусто?, `5` — печать.
Пример: `3 4 1,56 1,7 1,cat 2 5 4`. При ошибке в файле выполнение останавливается.

В путь можно указать файл или папку: каждый `.txt` в папке — отдельная точка графика.
Каждый файл прогоняется 5 раз, в график идёт минимальное время. Замеры хранятся в `results/*.csv` рядом с exe.

Готовые наборы лежат в `samples/` (копируются рядом с exe):
`stack/`, `queue_length/` (разная длина), `queue_composition/` (одна длина — разный состав), `postfix.txt`, `list.txt`.

## Структура
```
DynamicStructures/
  Core/   SinglyLinkedList, Stack, Queues, Expressions, Runner — логика без UI
  UI/     MainView (интерфейс кодом), Theme (палитра и стили)
DynamicStructures.Tests/   xUnit-тесты Core
samples/                   наборы входных данных
```
