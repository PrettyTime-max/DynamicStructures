# DynamicStructures

Практическая работа 3 по динамическим структурам данных. Настольное приложение на C# (WPF, .NET 10).

В проекте реализованы собственный односвязный список, стек и очередь на его основе, вычисление выражений, сравнение очередей по времени, четыре прикладных примера и двенадцать алгоритмов на списке.

## Запуск

Откройте `DynamicStructures.sln` в Visual Studio и запустите проект.

## Что умеет приложение

Режим выбирается в выпадающем меню, запуск по кнопке «Старт».

- **Часть 1.** Стек на собственном списке: операции из файла с замером времени, вычисление постфиксных выражений, перевод инфиксной записи в постфиксную.
- **Часть 2.** Очередь тремя способами (`List<T>`, собственный список, `Queue<T>`) и сравнение времени на наборах разной длины и состава.
- **Часть 3.** Примеры применения: хеш-таблица с цепочками (список), стек вызовов (стек), очередь печати с приоритетами (очередь), двоичная куча (дерево).
- **Часть 4.** Двенадцать алгоритмов на связном списке.

Если в папке несколько наборов данных, рядом с путём можно выбрать конкретный файл или выражение. В окне вывода сначала идёт итог, затем подробности. Ошибка в одной строке входного файла попадает в отчёт и не останавливает обработку остальных.

Для алгоритмов со стеком показывается анимация. Она останавливается, когда в стеке 30 элементов, с пояснением в окне. Сами вычисления и замеры при этом идут по всем данным.

## Структура

```
DynamicStructures/
  Core/             логика без интерфейса
    SinglyLinkedList.cs   список и алгоритмы части 4
    Stack.cs              стек на списке
    Queues.cs             три реализации очереди
    Expressions.cs        постфиксная и инфиксная запись
    Runner.cs             разбор файлов операций, замеры, набор алгоритмов части 4
    Applications.cs       примеры части 3
  UI/               окно, собранное кодом
samples/            входные файлы
ALGORITHMS.md       разбор алгоритмов с кодом
```

## Входные данные

Файлы лежат в `samples/` и копируются в папку сборки.

- `stack/` — наборы операций стека, от 8 до 50 000 операций.
- `queue_length/`, `queue_composition/` — наборы для очереди.
- `postfix.txt`, `infix.txt` и версии `*_errors.txt` с ошибками.
- `hashtable.txt`, `callstack.txt`, `printqueue.txt`, `heap.txt` — команды для примеров части 3.
- `list.txt`, `list_sorted.txt`, `list_two.txt` — списки для части 4.

Формат файла операций стека и очереди: коды через пробел. `1,значение` — вставка, `2` — удаление, `3` — просмотр первого элемента, `4` — проверка на пустоту, `5` — печать.

## Замеры времени

Для каждого файла и каждой реализации выполняется 5 прогонов, в итог идёт минимальное время считывания и выполнения.
